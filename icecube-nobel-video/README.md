# 冰下之眼 · 2026 诺贝尔物理学奖竖屏科普（60s）

`index.html` 是一段自动播放的 9:16 动画，供录屏成片使用；`subtitles.srt` 是与画面同一套时间轴的字幕，可导入剪映对齐配音。

## 录屏
1. 用 Chrome 打开 `index.html`，窗口调成竖长（或开发者工具设备模式选 1080×1920）。画面会自动按 9:16 居中缩放，鼠标指针自动隐藏。
2. 开始录屏后按 **R**（或空格）从 0 秒重播；按 **P** 暂停/继续。
3. 录满 60 秒，裁掉左右黑边即可。
